# 60-Day Work Plan — Day 1 to Day 60

> **The complete daily execution plan.** Same 10-hour block structure every day, with a clear Govt topic, Tech topic, and project for each day.
> Pair it with `RESOURCE_HUB.md` for exact links. Tick as you go.

**Daily blocks (every single day):**

| Block | Time | Track |
|---|---|---|
| B1 | 05:00–08:00 | Govt Learning |
| B2 | 09:00–12:00 | Tech Learning + Coding |
| B3 | 13:00–15:00 | Govt Practice + CA |
| B4 | 16:00–18:00 | Tech Build + Revision |

**Weekly rhythm:** Mon–Fri = new topics · Sat = practice + project · Sun = mock + review.
